Twee telefoons.
Eén eerste overdracht.

Telefoon A gebruikt Youfone en telefoon B Lebara, beide op het KPN-netwerk. Schakel op beide toestellen wifi en hotspot uit en mobiele data in. De afzonderlijke providerverklaringen zijn geen technische netwerkmeting. Telefoon A maakt een uitnodiging; telefoon B opent die. Bevestig je deelname, wissel een testcode uit en sluit de proef af voor een codevrij resultaat.

Er wordt geen account aangemaakt. Deze korte proef opent geen gewone chat of NOVA-contact. De testcodes gaan via de PALACO-server op Render. HTTPS beschermt het vervoer; de server kan de codes lezen. End-to-endversleuteling is nog niet aangesloten.

Controleer dat op beide telefoons hetzelfde proefnummer staat. De uitnodiging bewijst geen identiteit.

Mobiele-data-proef

Youfone → Lebara → Youfone. Twee aanbieders, maar hetzelfde onderliggende KPN-netwerk. Beide telefoons bevestigen uitsluitend hun eigen instellingen; RIO kan de provider of wifi-stand niet uitlezen.

Bevestig deze vier punten op beide telefoons apart voordat je de carrierproef uitvoert:

3 · Bevestig ontvangen codes op de andere telefoon.
4 · Antwoord op de ontvangen testcode.

    Heen-en-terug ontvangen: de twee browsers hebben de code en het passende antwoord bevestigd. Controleer de schermen van beide fysieke telefoons.

    Testcodes en tijdelijke koppelingen worden op de server uiterlijk na vijf minuten gewist, en ook bij afsluiten of een serverherstart. Een tijdelijk netwerkprobleem is geen bewijs van aflevering. Persoonlijke aanmelding en operationeel RIO-contact blijven gesloten.
