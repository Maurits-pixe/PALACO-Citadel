Twee telefoons.
Eén eerste overdracht.

Open deze pagina op je twee telefoons. Telefoon A maakt een uitnodiging; telefoon B opent die. Bevestig op beide toestellen dat je meedoet, stuur een testcode en laat de andere telefoon antwoorden.

Er wordt geen account aangemaakt. Deze korte proef opent geen gewone chat of NOVA-contact. De testcodes gaan via de PALACO-server op Render. HTTPS beschermt het vervoer; de server kan de codes lezen. End-to-endversleuteling is nog niet aangesloten.
