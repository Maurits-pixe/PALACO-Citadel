# PALACO-Citadel filtered authority boundaries

**Status:** implementation-facing review note; not a constitutional amendment  
**Date:** 2026-10-07

This note translates the inspected Citadel baseline into safe reading boundaries. The PALACO integration index is the source-filtering record; this file avoids copying its full content.

## What the current mainline supports

The Citadel README defines a layered reading order from foundation through core systems, evidence, governance, operations, intelligence, immortality and implementation. The existing provenance model requires the origin of meaning to remain demonstrable. QUAY connects action, origin, context and evidence.

The RIO transition profile is explicitly an implementation profile. It says `constitutional_authority_created: false` and that the profile does not create canon or authority. Its transition and gate tables are therefore runtime constraints within that profile, not a new source of constitutional power.

## Boundary rules

1. A conversation, dashboard, localization or UI label can communicate a proposed action; it cannot authorize it.
2. A transition table can restrict or reject a state change; it cannot invent a constitutional grant.
3. A proof, CI result or sealed evidence bundle remains scoped to its declared claim and time. It does not authorize runtime execution or publication by implication.
4. State changes append a new record with prior state, trigger, evidence, rationale, effective time and provenance. They do not rewrite earlier history.
5. RIO remains a communication and interaction surface. The review filter reserves the name RIO for the river concept and keeps it distinct from ELIXER capability/catalog language.
6. The spelling `VORM9EVING` is preserved exactly wherever the term is intentionally used.

## Classification

- Citadel foundation, QUAY and provenance files on `main`: canonical/implemented baseline according to their repository role.
- `rio/transition-policy.json`: implemented profile, explicitly non-authorizing.
- Open PRs and branch-only “Big Bang” or Emerald material: proposal or branch-scoped evidence until merged and independently verified.
- Conversation-derived ETCG/KAG/Linnaeus expansions: proposal/unverified in this repository snapshot.
