# BOTERHAM × Citadel Integration v0.1.0

BOTERHAM provides administrative monetary orchestration; the Citadel supplies identity, WORLD scope and constitutional context.

## Boundary
Citadel ID → WORLD ID → Currency Definition → Policy → Provenance/Watermerk → Authorization → BOTERHAM Ledger

HOLOGRAM and WATERMERK establish identity/authenticity/lineage. Neither independently grants monetary authority.

## Wallet
Four owner-selectable profiles remain canonical:
PHILANTROOP, MESCENICAS, MISANTROOP, BLANCO.

## WORLD currency
A Citadel/WORLD may prepare a currency definition through the generation engine. Publication, public issuance, custody, exchange or payment-service operation remains separately authorized.

## Fail-closed
Missing, expired or revoked authorization; invalid provenance; unsupported jurisdiction; prohibited compliance state; or invalid ledger state MUST stop execution.
