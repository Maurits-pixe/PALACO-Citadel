02 — WORLD CONSTITUTION IS NOT A COPY

De World Constitution is geen los gekopieerd document.

Het is een constitutional instance.

PALACO CONSTITUTION
        │
        │ inheritance / constraint
        ▼
EMERALD CONSTITUTION
        │
        │ bounded instantiation
        ▼
WORLD CONSTITUTIONAL INSTANCE

Daarmee kunnen individuele Worlds contextspecifieke bepalingen hebben, terwijl de hogere constitutionele grenzen onaantastbaar blijven.
