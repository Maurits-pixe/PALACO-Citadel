Client-side text encryption demonstration

LOCAL ENCRYPTION · SECURITY LIMITATIONS APPLY

Text is encrypted in this browser with AES-GCM-256 and a passphrase-derived key. Text and passphrases remain in this page's memory until cleared; nothing is uploaded or saved in the app. You can manually download encrypted output to this device. This demo is not an audited vault; browser/device compromise, weak passphrases, or lost passphrases can expose or permanently lose data. Avoid highly sensitive information.

Encrypt text locally

AES-GCM-256 · PBKDF2-SHA-256 · 600,000 iterations · random 16-byte salt and 12-byte IV

Local file transfer only: up to 4 MiB of plaintext and 6 MiB per encrypted file. The file contains ciphertext only; keep your passphrase separately.

Encrypted output starts with AETHER1. Keep it together with your passphrase stored separately. Losing either can make recovery impossible.

Encryption runs locally through the browser Web Crypto API. This page has no account, key recovery, automatic storage or sync, or independent security audit. Exported files remain under your device's file-handling and backup controls. Verify the code and protect your passphrase before relying on it.
