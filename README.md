# PALACO Citadel

First executable PALACO UI foundation.

## What is included

- Responsive website UI for desktop, tablet, and mobile.
- Basic interactive "GO" flow (save and show latest objective).
- Progressive Web App baseline (manifest + service worker).

## Run locally

From `/home/runner/work/PALACO-Citadel/PALACO-Citadel`:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Domain deployment

Deploy this folder as a static site to any HTTPS host and connect your domain DNS to that host.
